This report documents the design and development of a dynamic Excel dashboard for Week 3: Dynamic Data Visualization and Dashboard Development, continuing the hypothetical FreshKart retail scenario with 15,000 simulated transactions. It explains the purpose of replacing static weekly reports with an interactive single-screen dashboard showing historical trends and current KPIs. Data sources including Sales Transactions, Products, Stores, Targets and Week 2 calculated fields are outlined with types and refresh logic. Dashboard design principles such as 5-second readability, one-screen layout, and color with meaning are discussed. A conceptual wireframe illustrates the layout with four KPI cards, slicers and timeline, monthly revenue trend line chart, top-5 products bar chart, category donut chart, region performance table with data bars, and store-wise detail PivotTable. Detailed descriptions of Excel features used including PivotTables, PivotCharts, Slicers, Timelines, combo charts, conditional formatting with icon sets and data bars, GETPIVOTDATA and dynamic titles are provided. A 14-step creation guide, explanation of decision-making through interactive filtering, justification of chosen visualizations over alternatives, limitations and future Power BI migration plans are included to demonstrate advanced Excel skills and practical interactivity.
